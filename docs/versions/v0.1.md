## 目标

打通“终端输入 → 模型服务 → 流式终端输出”，使用真实模型服务完成一次文本问答，并理解配置加载、请求发送、响应处理和程序退出的完整流程。

## 已确认事项

- 项目使用 **Go** 构建。
- v0.1 聚焦最小模型调用链路：输入一段话，获得真实模型回复。
- 使用中转站提供的 **DeepSeek** 模型；Key、URL 和模型名称由用户在本机填写。
- 回复采用 **流式输出**，收到正文片段后立即显示。
- 每个版本的具体讨论、方案与验收单独记录。
- 本项目不使用面向百度内部研发流程的 `dev-flow` 技能。

## 本版方案

### 使用方式

在项目根目录配置 `.env`，然后执行：

```sh
go run ./cmd/johnny "你好，请简单介绍一下你自己"
```

程序进行一次文本请求，逐段输出正文并退出。`Ctrl+C` 可以取消请求。

后续由 v0.2 引入全局 `johnny` 命令，v0.6 引入 TUI。

### 模型协议与客户端

当前按中转站常见的 **OpenAI 兼容 Chat Completions** 协议实现，使用官方 `openai-go` SDK。中转站实际是否支持该协议，仍需真实调用验收。

请求发送到配置的 API 根地址下的 `chat/completions` 路径，并启用流式响应。模型名称原样使用中转站提供的标识。

v0.3 再结合实际使用经验建设统一模型接口。

### 工程结构

```text
Johnny-Code/
├── cmd/johnny/main.go
├── internal/
│   ├── config/
│   │   ├── config.go
│   │   └── config_test.go
│   └── model/
│       ├── client.go
│       └── client_test.go
├── .env.example
├── go.mod
├── go.sum
└── README.md
```

- `main.go`：读取输入、组织调用、输出状态，并处理取消和退出码。
- `config.go`：读取 `.env` 与环境变量，检查必要配置和 API 根地址。
- `client.go`：通过 SDK 发送流式请求，逐段输出正文，检查请求是否正常结束。
- 测试：通过本地模拟服务验证流式行为、错误和取消，无需真实 Key。

### 配置

在项目根目录的 `.env` 中填写：

```dotenv
JOHNNY_API_KEY=你的中转站Key
JOHNNY_BASE_URL=https://你的中转站地址/v1
JOHNNY_MODEL=中转站提供的模型名称
```

`JOHNNY_BASE_URL` 使用服务要求的 API 根地址，保留实际路径前缀，去掉完整调用地址末尾的 `/chat/completions`。例如接口为 `https://relay.example/gateway/v1/chat/completions`，这里填写 `https://relay.example/gateway/v1`。

环境变量优先于 `.env` 中的同名配置。配置加载使用 `godotenv`，本地 `.env` 被 Git 忽略，仓库只保留模板。请求沿用标准 HTTP 代理环境变量。

### 输出与错误处理

- 模型正文写入标准输出，等待提示与错误写入标准错误。
- 服务单独返回的推理字段不作为正文显示。
- 请求总时限为 5 分钟，取消后结束连接。
- v0.1 每次运行发送一次请求，关闭 SDK 的自动重试。
- 对缺失配置、错误地址、HTTP 错误、流内服务错误、连接失败和空回复给出明确提示；错误提示不回显服务端原始载荷。
- 首次取消后恢复默认信号处理，必要时再次 `Ctrl+C` 可以强制结束进程。
- 中途断流或模型以非正常原因结束时返回错误，保留已显示的部分内容。
- 正常退出码为 0，失败为 1，取消为 130；通过 `go run` 启动时，退出状态由 Go 工具转述。

## 验收标准

### 本地自动验证

- `.env` 可读取，环境变量可以覆盖同名配置。
- 请求保留中转站路径前缀，正确传递 Key、模型名称、用户输入与流式选项。
- 服务端收到客户端已显示首段内容的通知后才继续发送后续内容，以此验证即时输出。
- HTTP 错误、提前断流与不完整回复能够被识别。
- 取消请求可以终止正在读取的流。
- Go 测试、竞态检查、静态检查与编译通过。

### 真实服务验收

用户填写 `.env` 后运行一次中文问答，确认中转站协议、Key、URL 和模型名称均正确，且回复逐段显示；再观察 `Ctrl+C` 是否能中断请求。
