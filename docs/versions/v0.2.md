## 目标

完成安装后，在任意目录输入 `johnny` 即可启动程序，并在后续版本持续沿用这一入口。

## 已明确的使用需求

- 全局启动命令为 `johnny`。
- 用户可以在终端的任意目录调用程序。
- 本版先启动已有的问答能力，后续通过同一入口使用 Agent 和 TUI。

## 当前方向草案

### 使用体验

```sh
cd /path/to/your-project
johnny
```

### 命令入口与工作目录

- 安装过程把名为 `johnny` 的可执行入口放到终端能够搜索到的 `PATH` 中。
- 启动时默认以终端当前目录作为工作目录。
- 程序安装位置与用户正在处理的项目分别管理；后续文件工具、命令执行和项目配置按当前工作目录工作。
- 用户级模型配置可以供不同项目使用；项目级约定由当前项目提供。

### Go 项目的安装方向

利用 Go 的构建与安装能力生成 `johnny` 可执行文件。开发期先解决本地安装或链接与命令可发现性；正式分发渠道根据实际需要再确定。

本版同时考虑基本帮助与版本信息，便于确认程序能被正确调用。
