# 使用手册

本文描述当前版本的 TUI 行为：输入、快捷键、审批、任务区、内置命令和退出方式。权限规则见[权限模型](permissions.md)，配置项见[配置](configuration.md)。

## 启动

```sh
johnny           # 默认模式：逐次审批
johnny --read    # 只读模式
johnny --skip    # 放行模式
```

`--permission-mode default|read-only|allow` 是等价的长写法；同时使用短选项和长写法时必须一致，否则启动报错。

Johnny-Code 只支持在终端直接运行 `johnny` 进入 TUI。参数任务（`johnny "做一个任务"`）、管道和重定向会在读取配置前被拒绝，不请求模型，也不打开 `/dev/tty`。

- 每轮结束后继续等待输入，同一进程内保留用户消息、模型回复和工具结果。
- 输入完整的 `/exit`，或在空输入处按 `Ctrl+D`（EOF）正常退出；空行不发送请求。
- 任务执行期间不排队提交新任务；需要中途换方向时先 `Ctrl+C` 取消。

启动选项：

| 选项 | 说明 |
| --- | --- |
| `--model 名称` | 临时覆盖模型名，不改 `.env` |
| `--api 协议` | 临时覆盖协议：`anthropic-messages`、`openai-responses`、`openai-chat-completions` |
| `--read` / `--skip` | 选择只读 / 放行模式 |
| `--permission-mode 模式` | `default`、`read-only`、`allow` |
| `--max-turns 次数` | 每轮用户输入最多请求模型的次数，默认 100 |
| `--help` / `--version` | 显示帮助 / 版本与构建提交号；不读取模型配置 |

包含空格的模型名用引号包围。`--model` 只替换模型名，`--api` 只替换协议，服务地址和 Key 继续使用当前配置。

## 输入与编辑

| 操作 | 行为 |
| --- | --- |
| `Enter` | 发送当前任务 |
| `Alt+Enter` 或 `Ctrl+J` | 输入换行；Alt 组合键需要终端发送相应按键序列 |
| 粘贴多行文本 | 保留换行，按 `Enter` 后才提交；使用终端自带粘贴快捷键 |
| 左右方向键、Home/End、删除键 | 编辑输入 |
| 上下方向键 | 在多行内移动；位于首行/末行时切换本进程输入历史；斜杠菜单打开时改为选择菜单项 |
| 输入 `/` | 在输入框上方打开 Skill 和内置命令菜单；继续输入自动过滤 |
| 菜单中 `Enter` 或 `Tab` | 补全选中的命令；完整命令直接按 `Enter` 执行 |
| 菜单中 `Esc` | 关闭菜单；清空输入后重新输入 `/` 可再次打开 |
| 中文等输入法 | 组合文本和候选窗口跟随输入框中的真实光标位置 |

单次输入最多 10000 行；超限粘贴会整体拒绝并提示，不静默截断。

## 运行中的界面

- 执行期间，工具调用在输入框上方按顺序实时显示，使用终端可用高度；超过一屏时保留最新记录并在顶部提示更早条数。
- 本轮结束时清除实时进展，在最终回答前保留一行折叠摘要（已执行次数、工具名），按 `Ctrl+O` 展开最近一次过程。
- 模型正文流式接收并按 Markdown 渲染标题、列表、引用、表格和代码块；明确语言的代码块带语法高亮，未标注或纯文本按无高亮等宽显示。
- 目录树有单独排版规则：无围栏也能识别，不进行语法高亮；宽度足够时保持原始列，窄终端压缩数字列并把说明换行，树形分支不会被拆断。
- 调用链、关系图等自由排版内容保留原缩进换行，长说明不会被省略号截断。
- 当前使用深色终端样式，暂不提供主题切换。
- 生成期间状态区显示已接收字数，不把回答原文写入动态区域；响应结束后先提交折叠摘要，再提交排版后的正文。

## 任务区

有后台子任务或 workflow 时，输入框下边线之下、页脚之上常驻任务区，最多占终端高度的三分之一。单个子任务一行，显示 ID、描述、耗时和状态（运行中 / 等待审批）；workflow 显示大纲进度、当前步骤和运行中的任务。

```text
workflow 重构日志模块  2/4
✓ 1 调研现状
◆ 2 并行改造各子模块    3/5 个任务完成
    ◆ a1b2 改造 parser · 1m05s · 运行中
    ◆ c3d4 改造 writer · 1m05s · 等待审批
○ 3 集成测试
○ 4 汇总
```

- 单个子任务结束时打印一行完成、失败或取消；workflow 只在每步结束和整个工作流结束时打印汇总，不逐个任务打印。
- 放不下时按优先级保留：标题行、当前步骤及运行中的任务、未开始的步骤，最后把已完成的步骤折叠成一行。
- 终端太矮时只显示一行摘要，例如 `workflow 2/4 · 3/5 个任务 · 1 个等待审批`。
- 任务区每多一行，可见的对话记录就少一行，因此有高度上限。

## 审批

`default` 模式下，需要审批的操作会独占动态区域显示审批面板。来自子任务或 workflow 任务的请求标明来源，多个请求按先进先出排队；主 Agent 空闲时也能响应。

| 操作 | 行为 |
| --- | --- |
| `↑`/`↓`、`k`/`j` | 选择选项 |
| `Enter` | 确认当前选项 |
| `Ctrl+C` | 取消本轮和全部子任务，丢弃全部待审批请求，不执行待审批操作 |

四个选项：

1. **允许本次**：只执行这一次。
2. **拒绝本次**：默认焦点；不执行，并把拒绝原因告诉模型。
3. **本会话内允许**：只在当前 johnny 进程内有效，不写项目规则；主 Agent、子任务和 workflow 任务共享。只在请求带有可记住的授权键时出现。
4. **批准并记录**：写入项目规则 `.johnny/permissions.local.json`，后续同前缀自动执行；只在可记录时出现。

命中危险后缀和 `remember` 始终每次询问。队列中同键的待审批请求在显示前会重新检查；已经命中授权的请求自动放行。

## 内置命令

| 命令 | 行为 |
| --- | --- |
| `/permissions` | 查看固定白名单、危险后缀黑名单、项目规则和本会话授权；支持 `remove-command`、`remove-path`、`clear`、`clear-session` |
| `/context` | 查看上下文估算、窗口预算、缓存指标、摘要和工具输出存档 |
| `/compact` | 手动压缩较早的已完成轮次；压缩期间 `Ctrl+C` 取消 |
| `/memory` | 查看用户级和项目级 `MEMORY.md` 索引 |
| `/remember [内容]` | 让模型起草或更新项目 AGENTS，先展示拟修改内容，确认后写入 |
| `/skills` | 查看已加载、被项目级覆盖、未加载和未注入提示的 Skill |
| `/skills reload` | 重新扫描项目级和用户级 Skill 目录，并更新后续轮次的系统提示 |
| `/skill <name> [参数]` | 显式使用某个 Skill；正文直接进入本轮任务，终端只显示原始命令 |
| `/skill-name [参数]` | 每个 Skill 同时是独立命令，效果与 `/skill <name>` 相同 |
| `/exit` | 正常退出 |

内置命令优先于同名 Skill。例如存在名为 `exit` 的 Skill 时，`/exit` 仍然是退出，使用该 Skill 需要输入 `/skill exit`。

斜杠菜单打开时会列出全部 Skill 和内置命令，继续输入按名称过滤，`↑`/`↓` 选择，`Enter` 或 `Tab` 补全，`Esc` 关闭。选中后会补全为 `/skill-name ` 并留一个空格，便于继续输入参数；完整命令直接按 `Enter` 执行。

## 取消与退出

| 场景 | 行为 |
| --- | --- |
| 任务中 `Ctrl+C` | 取消本轮、全部子任务和运行中的 workflow，等待当前操作停止后继续输入；上下文和已完成修改保留 |
| 空闲时 `Ctrl+C` | 输入框有内容时清空输入；输入框为空且有子任务或 workflow 时取消全部 |
| `/exit` 或空输入 `Ctrl+D` | 正常退出；有子任务在运行时提示“N 个子任务将被取消”，取消并等待停止后退出 |
| 外部 SIGINT / SIGTERM / 终端挂断 | 取消任务并退出 |

退出码：成功为 0，失败为 1，进程取消为 130。TUI 内取消单轮后仍保留进程，之后正常退出为 0。

## 示例

第一轮：

```text
用 write 创建输出 hello 的 main.go，用 read 读取，用 edit 将 hello 改成 world，再用 bash 执行 go run main.go 并检查输出。
```

第二轮可以继续：

```text
把输出再改成 hello world，并重新运行。
```

后一次请求会携带当前会话历史。`johnny` 默认逐次审批，`go run` 这类命令需要批准；想跳过审批时使用 `johnny --skip`。
